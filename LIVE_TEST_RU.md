# Живой тест Jmail с новым Google-аккаунтом

Тестовый мастер запускается как Google Apps Script Web App. Пользователь начинает с экрана согласия Google, а затем проходит единый мастер настройки. Публичная страница GitHub Pages пока остаётся визуальным демо.

## Одноразовая подготовка владельцем проекта

Эта часть нужна один раз, чтобы создать ссылку мастера для пользователя.

1. Владелец проекта открывает [Apps Script](https://script.google.com/home/start) под своим Google-аккаунтом и создаёт новый проект.
2. Добавляет файл Code.gs и вставляет содержимое [готового кода Jmail](./apps-script/full-port/Code.gs).
3. Через кнопку «+» добавляет HTML-файл с именем `WebApp` и вставляет содержимое [WebApp.html](./apps-script/full-port/WebApp.html).
4. В Project Settings включает показ `appsscript.json` и заменяет его содержимое файлом [appsscript.json](./apps-script/full-port/appsscript.json).
5. Сохраняет проект, затем выбирает **Deploy → New deployment → Web app**.
6. Устанавливает **Execute as: User accessing the web app** и доступ для вошедших пользователей Google. Нажимает **Deploy** и сохраняет ссылку `/exec`.
7. При первом открытии тестовым пользователем Google покажет экран разрешений. Если появляется экран «непроверенное приложение», не продолжайте, пока не убедитесь, что это именно созданный владельцем Jmail проект. Для публичного запуска Google OAuth-проверка всё равно потребуется.

Для запуска теста ссылка `/exec` должна быть известна тестировщику. После её выдачи я добавлю её в кнопку подключения на публичной странице Jmail; до этого мастер можно открыть напрямую по ссылке.

## Проверка как нового пользователя

1. Откройте ссылку `/exec` в отдельном новом Gmail, предназначенном для поиска работы. Подтвердите разрешения, которые показывает Google.
2. Нажмите **Создать папку, таблицу и ярлыки**. Мастер создаст материалы в этом новом аккаунте.
3. Откройте [Google AI Studio — API keys](https://aistudio.google.com/app/apikey), создайте бесплатный Gemini API key и не включайте оплату. Вернитесь в мастер, вставьте ключ и нажмите **Проверить и сохранить**.
4. Загрузите резюме TXT, заполните имя, контакты и критерии. Проверьте факты, извлечённые из резюме, и подтвердите профиль. PDF/DOCX можно распознать локально на [странице Jmail](https://xurm1k.github.io/Jmail/), затем скачать текст.
5. Подпишитесь на одну job-alert рассылку, укажите адрес отправителя её письма в мастере и создайте фильтр Gmail.
6. В Gmail добавьте ярлык `Jmail/Вакансии` одному уже полученному тестовому письму, затем вернитесь в мастер и нажмите **Обработать тестовое письмо**.
7. Проверьте таблицу, папку Drive, Gmail-ярлыки и черновики. Только после удачного результата нажмите **Включить ежедневный запуск**.

## Бесплатный Gemini и данные

Gemini выбран потому, что он уже поддерживается и ключ выдаётся в Google AI Studio того же аккаунта. Бесплатные модели и квоты зависят от региона и меняются. При превышении квоты запрос остановится. Резюме и тексты писем отправляются Google Gemini; на бесплатном тарифе Google может использовать переданные данные для улучшения продуктов. Загружайте только то, что готовы передать Google. [Тарифы и условия Gemini](https://ai.google.dev/gemini-api/docs/pricing)

## Что означает успешный результат

Мастер от лица тестового пользователя создал папку, таблицу, ярлыки, Gmail-фильтр и ежедневный триггер. Gemini оценил тестовое письмо; подходящая вакансия и связанные материалы появились в Google Sheets, Drive и Gmail.

Если Google не даёт подтвердить доступ, или любой шаг завершается ошибкой, остановите тест и сохраните текст ошибки из Apps Script → Executions. Не отправляйте ключ Gemini, резюме или содержимое писем.
