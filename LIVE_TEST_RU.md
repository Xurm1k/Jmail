# Jmail: запуск для нового пользователя

## Один раз со стороны владельца проекта

Владелец разворачивает общий мастер Jmail как Google Apps Script Web App. При публикации выбирает **Execute as: User accessing the web app** и доступ **Anyone with Google account**. Затем адрес мастера (оканчивается на /exec) указывается один раз в конфигурации GitHub Pages. Пользователям этот адрес искать или вводить не нужно.

Для Apps Script создаётся один общий проект; пользователи открывают его под своими Google-аккаунтами. Папка, таблица, ярлыки, настройки и API key создаются/хранятся отдельно в аккаунте каждого пользователя. Скрипт не должен запускаться от имени владельца.

## Что делает новый пользователь

1. Открывает сайт Jmail и нажимает **Начать настройку**.
2. Выбирает отдельный Gmail для поиска работы и подтверждает запрошенный Google доступ.
3. Создаёт личную папку и таблицу кнопкой Jmail.
4. Подключает собственный Gemini API key. Кнопка ведёт в Google AI Studio; квоты и бесплатные условия Google могут меняться.
5. Загружает CV в PDF, DOCX или TXT, задаёт город, должности, критерии и предел поездки, проверяет сформированный профиль и подтверждает его.
6. Использует этот Gmail для регистрации на сайтах поиска работы и включает job-alert письма.
7. Нажимает **Проверить новые письма**. Jmail сам проверяет входящие письма за последние сутки; вручную ставить ярлыки и создавать фильтры не нужно.
8. Проверяет таблицу, папку и черновики. После успешной проверки включает ежедневный запуск.

## Что происходит с письмами

Gemini классифицирует свежие письма. Письма не о вакансиях и вакансии ниже заданных критериев перемещаются в корзину. Сомнительные вакансии получают ярлык Jmail/Проверить. Ошибки анализа оставляют письмо во входящих, чтобы его можно было обработать повторно. Отклики автоматически не отправляются.

Jmail передаёт Google Gemini текст почты, CV и критерии. Используйте только отдельный Gmail и проверьте первые результаты. Для доступа пользователей к Gmail Google показывает экран разрешений; до публичного запуска мастер может показывать предупреждение о непроверенном приложении, пока владелец не завершит OAuth-проверку Google.
