# Настройка MVP Jmail

Пользовательский порядок запуска и проверки обновляется в [`LIVE_TEST_RU.md`](./LIVE_TEST_RU.md). Он охватывает подключение отдельного Google-аккаунта, Gemini, загрузку и подтверждение CV-профиля, кнопку Apply и управление из финальной страницы.

## Важное для владельца

- Google Apps Script должен быть опубликован как Web App с выполнением от имени **User accessing the web app**.
- У пользователя должны оставаться его личные Google-файлы и аккаунт-specific User Properties.
- Перед изменением опубликованного скрипта сохранить резервную копию текущих файлов и deployment.
- Не публиковать API keys, резюме и письма в репозитории или логах.
- Google OAuth проверка, fresh-account flow и account-isolation не следует называть завершёнными без соответствующих проверок.

Подробности текущего потока и его ограничения: [`README.md`](./README.md), [`ARCHITECTURE.md`](./ARCHITECTURE.md), [`privacy.html`](./privacy.html).
