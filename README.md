# Jmail Alternative — прототип нового пользовательского сценария

Это отдельный, безопасный для показа PWA-прототип интерфейса Jmail. Он не подключается к Gmail, Google Drive, Google Sheets или Gemini и не изменяет файлы исходных проектов.

## Как посмотреть

1. Для быстрой оценки откройте `index.html` двойным щелчком в браузере. Для установки как PWA и проверки офлайн-оболочки используйте GitHub Pages или локальный HTTP-сервер.
2. Перейдите между разделами «Обзор», «Вакансии», «Мой профиль» и «Данные и доступ».
3. Измените критерии, сохраните их и нажмите «Проверить новые вакансии».

Можно также опубликовать папку как статическую страницу GitHub Pages: в настройках репозитория выберите публикацию из корня основной ветки. Сборка и API-ключи не нужны; библиотеки для чтения PDF и DOCX автоматически загружаются с CDN. Не публикуйте этот прототип в репозитории основного Jmail: он создан для отдельного просмотра.

## Что показывает прототип

- интерфейс «приложения», а не экран выдачи длинного скрипта;
- стартовый обзор со статусом подключения и результатами обработки;
- карточки вакансий с объяснением сильных совпадений и неопределённости;
- настройку порога и личных критериев;
- переключение светлой/тёмной темы и русский, немецкий или английский интерфейс;
- локальный импорт TXT, DOCX и текстовых PDF-резюме с автоматическим распознаванием имени, контактов и ключевых навыков;
- заметную рекомендацию создать отдельный Gmail для сайтов поиска работы и Jmail, с предупреждением о риске ошибок автоматизации;
- раздел контроля данных и доступа Google;
- безопасную модель: решение об отклике остаётся у пользователя, сомнительные вакансии отправляются на ручную проверку.

Все вакансии в примере вымышлены. Кнопки подключения и обработки имитируют сценарий и не обращаются к Google/Gemini. Тему и язык интерфейс сохраняет в `localStorage`; содержимое загруженного резюме не сохраняется и не отправляется на сервер. PDF/DOCX чтение использует библиотеки из CDN; загружается только код библиотек, файл остаётся в браузере. Для production разумно будет размещать эти библиотеки рядом с сайтом и фиксировать версии.
