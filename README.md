# Jmail

Jmail проводит пользователя от выбора отдельного Google-аккаунта и загрузки CV до настройки таблицы, папки, профиля критериев и ежедневной обработки писем с вакансиями.

## Как устроен доступ

Владелец один раз публикует общий Apps Script Web App и связывает его адрес с GitHub Pages. Каждый пользователь открывает тот же мастер, выбирает свой Google-аккаунт и выдаёт разрешения напрямую Google. Выполнение должно быть настроено как **User accessing the web app**: пользовательские письма, документы и свойства сохраняются в его аккаунте. Копировать скрипт или создавать таблицы вручную не требуется.

Пользователю нужен собственный Gemini API key с доступной квотой. Jmail проверяет новые письма, создаёт таблицу и материалы для отклика; отправка откликов остаётся под контролем пользователя. Не-вакансии и неподходящие вакансии перемещаются в корзину, сомнительные получают ярлык проверки. Используйте отдельный Gmail.

## Запуск и тестирование

Подробный путь владельца и пользователя описан в [инструкции запуска](./LIVE_TEST_RU.md). Текущий интерфейс публикуется через GitHub Pages из ветки main; общий Google мастер должен быть настроен отдельно и подключён в webapp-config.js.

Синтетические скрипты доступны в apps-script/full-port/ и используют заглушки Google API.
