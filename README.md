# Jmail

Ветки проекта:
- `main` — публичное демонстрационное приложение GitHub Pages;
- `Jmail_beta` — сохранённая старая версия;
- `Jmail_mvp` — текущий пилот: пользовательский Apps Script Web App и полный worker Job Automation.

## Демонстрация

Откройте GitHub Pages или `index.html`: можно просмотреть интерфейс, критерии поиска и извлечение текста резюме. Публичная страница пока не связана с Google и показывает примеры.

## Живой пилот

Прочитайте [пошаговый тест с новым Google-аккаунтом](./LIVE_TEST_RU.md). Владелец один раз разворачивает общий Google Apps Script Web App. Затем тестовый пользователь открывает его ссылку, подтверждает Google-доступ, получает личный Gemini API key, загружает TXT резюме и проходит настройку. Папка Drive, таблица, ярлыки, фильтр Gmail и расписание создаются мастером.

Внутри Apps Script используется User Properties, чтобы ключ, профиль и ID ресурсов каждого аккаунта хранились отдельно. Код API key не содержит. Текст резюме и почты отправляется в Google Gemini для анализа; изучите бесплатные условия Google перед тестом.

Публичная GitHub Pages ещё не соединена с URL Web App. Для полного пользовательского входа кнопка подключения на сайте должна получить ссылку после одноразового развертывания. Не публикуйте настоящие резюме и API keys в GitHub.

## Синтетическая проверка

Из корня репозитория:

- `node apps-script/full-port/profile_builder_test.mjs`
- `node apps-script/full-port/synthetic_test.mjs`
- `node apps-script/full-port/integration_test.mjs`

Тесты используют синтетические данные и заглушки Google API; они не проверяют реальный OAuth, Gmail или Gemini.
