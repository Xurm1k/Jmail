# Jmail Alternative — прототип нового пользовательского сценария

Это отдельный PWA-прототип пользовательского интерфейса Jmail. Ветки проекта:
- `main` — публичное демонстрационное приложение;
- `Jmail_beta` — сохранённая старая версия;
- `Jmail_mvp` — демонстрация плюс отдельный Apps Script worker для закрытого пилота.

## Как посмотреть демо

Откройте GitHub Pages или `index.html` в браузере и перейдите между разделами «Обзор», «Вакансии», «Мой профиль» и «Данные и доступ». Демо не подключается к Google/Gemini и показывает вымышленные вакансии.

## Состояние пилота

Это ещё не готово к реальному запуску: полный скрипт прошёл только синтетические проверки. Мастер настройки уже формирует профиль из резюме и показывает его на проверку; живой запуск всё ещё не проверен. Для реального теста нужны Gemini API key и подтверждение доступа Google. Публичный сайт на `main` остаётся демо.

В интерфейсе ветки `Jmail_mvp` можно скачать [один файл полного Apps Script](./apps-script/full-port/Code.gs) и локально извлечённый TXT резюме; [инструкция настройки](./apps-script/full-port/SETUP_RU.md) описывает подключение мастера.

## Закрытый пилот

Основной перенос Job Automation с проверками, Google Maps, PDF, месячной таблицей и черновиками: [инструкция полного пилота](./apps-script/full-port/SETUP_RU.md), [исходники](./apps-script/full-port/). Упрощённый worker в [apps-script/Code.gs](./apps-script/Code.gs) оставлен как ранний прототип.

Пилот запускается внутри Google аккаунта пользователя. Он анализирует почту с выбранным ярлыком и записывает результаты в таблицу. Защитные значения по умолчанию: worker не удаляет и не архивирует письма, не отправляет отклики и не создаёт черновики. PWA и worker пока не соединены кнопкой: публичная работающая интеграция требует отдельного OAuth и релизного этапа.

Не публикуйте настоящие резюме, ключи или другие секреты в GitHub. Для пилота пользователь сам подтверждает доступ Google и задаёт секреты в свойствах Apps Script.

Сравнение архитектур и этапы продукта: [ARCHITECTURE.md](./ARCHITECTURE.md).
### Проверка без Google аккаунта

Для раннего упрощённого worker: `node apps-script/synthetic_test.mjs` (успех и ошибки Gemini/сети). Для перенесённой логики отбора Job Automation: `node apps-script/full-port/synthetic_test.mjs` (8 решений по порогу, доказательствам, типу вакансии и маршруту). Оба набора работают на синтетических данных; Google OAuth, реальные письма и Gemini не вызываются.
