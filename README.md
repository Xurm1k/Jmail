# Jmail

## Публичная страница

GitHub Pages публикует файл index.html из ветки main. Сейчас там доступен визуальный прототип; он ещё не подключён к Google Apps Script.

## Мастер настройки

Рабочий мастер настраивается как Google Apps Script Web App. После одноразового развёртывания владельцем Google выдаёт ссылку /exec; её нужно добавить в кнопку публичной страницы. Тестовому пользователю не нужно вручную ставить Gmail-ярлыки: скрипт сам проверяет новые письма во «Входящих» за последние сутки, определяет письма с вакансиями, сравнивает вакансии с профилем и автоматически удаляет в корзину неподходящую почту.

Подробности — в [инструкции живого теста](./LIVE_TEST_RU.md). Для пилота используйте отдельный Gmail. Gemini API key и профиль сохраняются в личных свойствах пользователя Apps Script; не публикуйте ключи и резюме в GitHub.
