# Полный перенос Job Automation в Jmail: закрытый пилот

Для живого теста используй короткую инструкцию [LIVE_TEST_RU.md](../../LIVE_TEST_RU.md). Она рассчитана на человека с новым Gmail и готовым резюме.

## Что делает этот пилот

- Работает в Apps Script и Google аккаунте самого пользователя.
- Создаёт таблицу, папку Google Drive, ярлыки Gmail и Gmail-фильтр по адресам отправителей, которые выбрал пользователь.
- Сохраняет пользовательский Gemini API key только в свойствах его Apps Script; ключ проверяется до сохранения.
- Создаёт PDF и черновики отклика. Отправлять отклик должен пользователь.
- Позволяет включить и отключить ежедневный запуск из меню таблицы.

## Ограничение текущего пользовательского пути

Публичная GitHub Pages пока показывает демо и не подключается к Google сама. Для живого пилота пользователь один раз создаёт личный Apps Script-проект, вставляет единый файл Code.gs, включает appsscript.json и запускает setupJmail. После этого профиль, ключ, фильтры и расписание настраиваются в созданной таблице. Это тестовый путь; он пока не равен полностью автоматическому подключению из PWA.

## Синтетические проверки

Из корня репозитория выполнить:

`node apps-script/full-port/profile_builder_test.mjs`
`node apps-script/full-port/synthetic_test.mjs`
`node apps-script/full-port/integration_test.mjs`

Проверки используют синтетические данные и подменённые Google-сервисы. Они не подтверждают работу в реальном аккаунте или доступность Gemini API.
