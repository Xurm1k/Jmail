Помощник по поиску работы

Работа, которая подходит именно вам.

Jmail проверяет письма с вакансиями по вашему резюме и критериям, создаёт таблицу и документы для отклика. Все материалы сохраняются в вашем Google-аккаунте.

Начать настройку  →
Чтобы Google не перепутал аккаунты, откройте Jmail в приватном окне и войдите там только в отдельный Gmail для поиска работы.

Как проходит настройка

1
Вы выбираете отдельный Google-аккаунтGoogle показывает разрешения; данные создаются в выбранном аккаунте.
2
Загружаете CV и задаёте критерииJmail извлекает факты и предлагает профиль для проверки.
3
Получаете готовую автоматизациюПапка, таблица, документы и ежедневная проверка писем.
Создайте отдельный Gmail для поиска работы. Jmail проверяет новые письма и может перемещать их в корзину, если сочтёт письмом не о вакансии или неподходящей вакансией. Первые результаты проверьте. Тексты писем, резюме и критерии передаются Google Gemini. Отклики не отправляются без вашего действия.

Почта и Google-файлы

Jmail работает в аккаунте пользователя и создаёт его папку, таблицу и ярлыки.

Ваши критерии

Оценка вакансий учитывает резюме, желаемые должности, город, формат и ограничения.

Вы управляете запуском

Сначала можно проверить вручную, затем включить ежедневный запуск и остановить его в любой момент.

Получить и подключить Gemini API key

  1. Откройте AI Studio под тем же отдельным Google-аккаунтом, который выберете для Jmail. Не используйте основную почту.
  2. Если открылся основной аккаунт, нажмите на аватар Google и переключитесь на отдельный рабочий аккаунт.
  3. Нажмите «Create API key».
  4. Если появится выбор проекта, оставьте проект по умолчанию. Новый проект создавать не нужно; не подключайте оплату — используйте бесплатный вариант.
  5. Скопируйте ключ. Вернитесь в мастер и вставьте его в поле «Ключ Gemini», затем нажмите «Проверить и сохранить ключ».
Открыть Google AI Studio
Для анализа нужен Gemini API key с доступной квотой. Не подключайте основной почтовый аккаунт. Перед первым использованием прочитайте разрешения Google.
