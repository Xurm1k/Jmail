Конфиденциальность и использование данных

Важно. Jmail — проект Apps Script, поддерживаемый владельцем репозитория Xurm1k. Это уведомление описывает текущий код и не означает, что приложение прошло проверку OAuth Google. Перед разрешением доступа прочитайте список разрешений на экране Google.

Какие данные обрабатываются

Для настройки и работы Jmail пользователь может передать текст резюме, имя, контактную почту, телефон, город, критерии поиска, минимальную оценку совпадения и максимальное время в пути. При проверке вакансий Jmail читает темы и содержимое писем из Gmail, включая текст и HTML. Для создания документов могут обрабатываться сведения профиля и содержание подходящих вакансий.

Файл резюме читается в браузере; Jmail отправляет на обработку извлечённый текст, а не загружает исходный файл в отдельное хранилище Jmail. Язык и тема интерфейса сохраняются в локальном хранилище браузера.

Зачем и куда передаются данные

Jmail использует Google Apps Script и выполняется от имени вошедшего пользователя. Текст резюме, профиль, критерии и содержимое писем передаются через HTTPS в Google Gemini API с API-ключом, который вводит сам пользователь. Это нужно для составления профиля, оценки вакансий и подготовки документов. Передача начинается после отдельного согласия в приложении.

Ключ Gemini, профиль, критерии, контактные данные, идентификаторы созданных ресурсов и сводка запусков хранятся в пользовательских свойствах Apps Script, отдельно для каждого Google-аккаунта. Jmail не содержит собственной общей базы профилей и ключей. Таблица, папка и созданные PDF находятся в Google Drive пользователя.

Скрипт может архивировать подходящие письма, переносить неподходящие письма в корзину, создавать черновики откликов и отправлять уведомления самому пользователю. Письма работодателям автоматически не отправляются.

Gemini и обработка у Google

Google обрабатывает запросы Gemini по условиям выбранного пользователем региона и типа квоты. Для бесплатной квоты вне Европейской экономической зоны Google может использовать запросы и ответы для улучшения продуктов, а специалисты могут просматривать их. Условия Google для пользователей ЕЭЗ распространяют правила обработки платного режима и на бесплатную квоту. Проверьте актуальные условия Gemini API перед отправкой резюме и писем. Jmail не может удалить данные, уже переданные Gemini.

Использование данных Google Workspace

Jmail использует и передаёт данные Google Workspace только для функций поиска работы, создания таблицы и подготовки документов, видимых в приложении, и только после согласия пользователя. Jmail не продаёт эти данные, не использует их для рекламы и не применяет для обучения собственных моделей. Использование регулируется политикой Google Workspace User Data, включая требования Limited Use; условия самого Gemini применяются отдельно.

Удаление данных и отзыв доступа

Кнопка «Удалить мои данные и отключить Jmail» удаляет сохранённые профиль, критерии, API-ключ и настройки, останавливает ежедневный запуск и пытается удалить фильтры и ярлыки Jmail. Письма с ярлыками Jmail возвращаются во «Входящие». Таблица и папка Jmail перемещаются в корзину Google Drive; пользователь может отдельно очистить корзину. Gmail-черновики и уже отправленные уведомления не удаляются. Удаление в Jmail не отзывает и не стирает запросы, ранее отправленные Gemini. Доступ также можно отозвать в настройках Google-аккаунта в разделе подключений сторонних приложений.

Защита и обращения

Jmail не ведёт отдельный сервер с общей базой пользовательских профилей. Обработка и хранение происходят в сервисах Google и аккаунте пользователя. Владелец проекта поддерживает общий код Apps Script; пользователь должен проверять запрашиваемые разрешения и может отозвать их.

Вопросы о приватности можно направить сопровождающему через репозиторий Jmail на GitHub. Не публикуйте там резюме, адреса почты, API-ключи или другие личные данные; в обращении попросите приватный канал связи.

Data processed

To set up and use Jmail, a user may provide resume text, name, contact email, phone number, city, job criteria, minimum match score, and maximum commute time. During a check, Jmail reads Gmail message subjects and content, including plain text and HTML. Profile details and suitable job descriptions may be processed to create documents.

The resume file is read in the browser. Jmail sends extracted text for processing; it does not upload the original file to a separate Jmail storage service. Interface language and theme are stored in the browser's local storage.

Purpose and data flows

Jmail uses Google Apps Script and runs as the signed-in user. Resume text, profile, criteria, and email content are sent over HTTPS to the Google Gemini API using an API key entered by the user. This is used to build the profile, assess jobs, and prepare documents. Processing starts after the user gives separate consent in Jmail.

The Gemini key, profile, criteria, contact details, IDs of created resources, and run summaries are stored in Apps Script User Properties, separately for each Google account. Jmail has no shared database of user profiles or keys. The spreadsheet, folder, and generated PDFs are stored in the user's Google Drive.

The script may archive suitable messages, move unsuitable messages to Trash, create application drafts, and send notifications to the user. It does not automatically send applications to employers.

Gemini and Google's processing

Google processes Gemini requests under the terms for the user's region and quota type. Outside the European Economic Area, Google may use unpaid-tier prompts and responses to improve products, and human reviewers may process them. Google's EEA terms extend paid-service data handling rules to unpaid quota. Review the current Gemini API terms before sending resumes or email. Jmail cannot delete data already sent to Gemini.

Google Workspace data use

Jmail uses and transfers Google Workspace data only to provide the job-search, spreadsheet, and document features visible in the app, and only after user consent. Jmail does not sell this data, use it for advertising, or use it to train its own models. Use is subject to the Google Workspace User Data Policy, including Limited Use; Gemini's own terms apply separately.

Deletion and access revocation

The “Delete my data and disconnect Jmail” button deletes the saved profile, criteria, API key, and settings; stops the daily run; and attempts to remove Jmail filters and labels. Messages carrying Jmail labels are returned to Inbox. The Jmail spreadsheet and folder are moved to Google Drive Trash; the user may empty Trash separately. Gmail drafts and notifications already sent are not deleted. Jmail deletion cannot retract requests previously sent to Gemini. Access can also be revoked from the Google Account's third-party connections settings.

Security and contact

Jmail does not operate a separate server database of user profiles. Processing and storage take place in Google services and the user's account. The project maintainer controls the shared Apps Script code; users should review requested permissions and can revoke them.

For privacy questions, contact the maintainer through the Jmail GitHub repository. Do not post a resume, email address, API key, or other personal data publicly; ask for a private contact channel.

Verarbeitete Daten

Für Einrichtung und Nutzung kann der Nutzer Lebenslauftext, Name, Kontakt-E-Mail, Telefonnummer, Stadt, Suchkriterien, Mindest-Matchwert und maximale Fahrzeit angeben. Bei einer Prüfung liest Jmail Betreff und Inhalt von Gmail-Nachrichten, einschließlich Text und HTML. Profildaten und passende Stellenbeschreibungen können zur Erstellung von Dokumenten verarbeitet werden.

Die Lebenslaufdatei wird im Browser gelesen. Jmail übermittelt den extrahierten Text zur Verarbeitung, lädt die Originaldatei aber nicht in einen eigenen Jmail-Speicher hoch. Sprache und Darstellung werden im lokalen Browserspeicher abgelegt.

Zweck und Datenflüsse

Jmail verwendet Google Apps Script und läuft als der angemeldete Nutzer. Lebenslauftext, Profil, Kriterien und E-Mail-Inhalte werden über HTTPS mit einem vom Nutzer eingegebenen API-Schlüssel an die Google Gemini API gesendet. Dies dient der Profilerstellung, Stellenbewertung und Dokumentvorbereitung. Die Verarbeitung beginnt erst nach einer separaten Zustimmung in Jmail.

Gemini-Schlüssel, Profil, Kriterien, Kontaktdaten, IDs der erstellten Ressourcen und Laufzusammenfassungen werden in Apps-Script-User-Properties gespeichert, getrennt nach Google-Konto. Jmail betreibt keine gemeinsame Datenbank für Nutzerprofile oder Schlüssel. Tabelle, Ordner und erzeugte PDFs liegen im Google Drive des Nutzers.

Das Skript kann passende Nachrichten archivieren, unpassende in den Papierkorb verschieben, Bewerbungsentwürfe erstellen und Benachrichtigungen an den Nutzer senden. Bewerbungen an Arbeitgeber werden nicht automatisch versendet.

Gemini und Datenverarbeitung durch Google

Google verarbeitet Gemini-Anfragen gemäß den Bedingungen für Region und Kontingent des Nutzers. Außerhalb des Europäischen Wirtschaftsraums darf Google Eingaben und Antworten des kostenlosen Kontingents zur Produktverbesserung verwenden; auch menschliche Prüfer können sie verarbeiten. Für Nutzer im EWR gelten die Regeln zur Datenverarbeitung des kostenpflichtigen Dienstes auch für kostenlose Kontingente. Lesen Sie die aktuellen Gemini-API-Bedingungen, bevor Sie Lebensläufe oder E-Mails senden. Jmail kann bereits an Gemini übermittelte Daten nicht löschen.

Nutzung von Google-Workspace-Daten

Jmail verwendet und überträgt Google-Workspace-Daten ausschließlich zur Bereitstellung der in der App sichtbaren Jobsuche-, Tabellen- und Dokumentfunktionen und nur nach Zustimmung des Nutzers. Jmail verkauft diese Daten nicht, nutzt sie nicht für Werbung und trainiert damit keine eigenen Modelle. Es gilt die Google Workspace User Data Policy einschließlich Limited Use; die Gemini-Bedingungen gelten zusätzlich.

Löschen und Zugriff widerrufen

Die Schaltfläche „Meine Daten löschen und Jmail trennen“ löscht gespeichertes Profil, Kriterien, API-Schlüssel und Einstellungen, stoppt den Tageslauf und versucht, Jmail-Filter und Labels zu entfernen. Nachrichten mit Jmail-Labels werden in den Posteingang zurückverschoben. Die Jmail-Tabelle und der Ordner werden in den Google-Drive-Papierkorb verschoben; der Nutzer kann diesen separat leeren. Gmail-Entwürfe und bereits gesendete Benachrichtigungen bleiben erhalten. Bereits an Gemini gesendete Anfragen kann Jmail nicht zurückrufen. Der Zugriff kann außerdem in den Einstellungen des Google-Kontos unter Drittanbieter-Verbindungen widerrufen werden.

Sicherheit und Kontakt

Jmail betreibt keine separate Serverdatenbank mit Nutzerprofilen. Verarbeitung und Speicherung erfolgen in Google-Diensten und im Konto des Nutzers. Der Projektbetreuer kontrolliert den gemeinsamen Apps-Script-Code; Nutzer sollten Berechtigungen prüfen und können sie widerrufen.

Datenschutzfragen können über das Jmail-GitHub-Repository an den Betreuer gerichtet werden. Veröffentlichen Sie dort keinen Lebenslauf, keine E-Mail-Adresse, keinen API-Schlüssel und keine anderen personenbezogenen Daten; bitten Sie um einen privaten Kontaktweg.
